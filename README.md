# 🖤 Evian Blackout App

テキストの一部を黒塗りにできるシンプルなWebアプリケーションです。

## 機能

- テキストの入力
- マウスで選択した部分を黒塗りに変換
- 黒塗りしたテキストを画像としてダウンロード
- レスポンシブデザイン対応

## 使い方

1. テキストエリアに黒塗りしたいテキストを入力
2. 「テキストを読み込む」ボタンをクリック
3. 表示されたテキストから黒塗りにしたい部分をマウスで選択
4. 「選択部分を黒塗りにする」ボタンをクリック
5. 必要に応じて「画像としてダウンロード」で保存

## 技術スタック

- HTML5
- CSS3
- Vanilla JavaScript
