# 🖤 Evian Blackout App

画像内のテキストやプライバシー情報を黒塗りにできるWebアプリケーションです。

## 機能

✨ **主な機能**
- 📸 画像のアップロード（ドラッグ&ドロップ対応）
- 🖱️ マウスドラッグで黒塗りエリアを選択
- 📱 タッチ操作対応（スマートフォン・タブレット）
- ↩️ 最後の黒塗りを取り消し
- 🔄 すべてリセット
- 💾 編集後の画像をダウンロード（PNG形式）
- 📐 レスポンシブデザイン

## 使い方

1. **画像をアップロード**
   - クリックして画像を選択、またはドラッグ&ドロップ
   - PNG, JPG, GIF対応（最大10MB）

2. **黒塗りエリアを選択**
   - マウスをドラッグして黒塗りにしたい部分を選択
   - 複数のエリアを選択可能

3. **編集・保存**
   - 「最後の黒塗りを取り消す」で直前の操作を取り消し
   - 「すべてリセット」ですべての黒塗りをクリア
   - 「画像をダウンロード」で編集後の画像を保存

## 使用例

- 📄 契約書や請求書の個人情報保護
- 💳 クレジットカード情報の一部を隠す
- 📧 メールやメッセージのスクリーンショットから機密情報を隠す
- 🏷️ 商品写真（evianボトルなど）のラベル情報を編集

## 技術スタック

- Canvas API
