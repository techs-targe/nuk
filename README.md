# 🖤 Evian Blackout App

画像内のテキストやプライバシー情報を黒塗りにできるWebアプリケーションです。

## 機能

✨ **主な機能**
- 📸 画像のアップロード（ドラッグ&ドロップ対応）
- 📷 **カメラで直接撮影**（スマホ・PCカメラ対応）
- 🤖 **AI自動検出**：画像内に「evian」の文字があれば自動検出してポップアップ表示
- 🖱️ マウスドラッグで黒塗りエリアを選択
- 📱 タッチ操作対応（スマートフォン・タブレット）
- ↩️ 最後の黒塗りを取り消し
- 🔄 すべてリセット
- 💾 編集後の画像をダウンロード（PNG形式）
- 📐 レスポンシブデザイン

## 使い方

### 方法1：画像をアップロード
1. クリックして画像を選択、またはドラッグ&ドロップ
2. PNG, JPG, GIF対応（最大10MB）

### 方法2：カメラで撮影
1. 「カメラで撮影」ボタンをクリック
2. カメラへのアクセスを許可
3. evianボトルなどを撮影
4. 「撮影する」ボタンで画像をキャプチャ

### 画像読み込み後
- **自動検出**：画像内に「evian」の文字が含まれていれば、自動的にポップアップで通知
- 「画像を解析中...」と表示されている間、OCR処理が実行されます

### 黒塗り編集
1. マウスをドラッグして黒塗りにしたい部分を選択
2. 複数のエリアを選択可能
3. 「最後の黒塗りを取り消す」で直前の操作を取り消し
4. 「すべてリセット」ですべての黒塗りをクリア
5. 「画像をダウンロード」で編集後の画像を保存

## 使用例

- 📄 契約書や請求書の個人情報保護
- 💳 クレジットカード情報の一部を隠す
- 📧 メールやメッセージのスクリーンショットから機密情報を隠す
- 🏷️ 商品写真（evianボトルなど）のラベル情報を編集

## 技術スタック

- HTML5 Canvas
- CSS3
- Vanilla JavaScript
- **Tesseract.js** - OCR（光学文字認識）ライブラリ
- **MediaDevices API** - カメラアクセス
- FileReader API
- Canvas API
